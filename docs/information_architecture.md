**Version:** 1.0

**Status:** Approved

---

# Purpose

The Information Architecture (IA) defines how the website is structured, how users navigate through it, and how information is organized before development begins.

Its objectives are to:

- Create a clear website structure.
- Improve user experience.
- Reduce development ambiguity.
- Ensure every page supports the business goals.
- Prepare for wireframing and UI design.

---

# Business Goal

The primary goal of the website is to increase service bookings while establishing trust and making it easy for customers to contact the garage.

Primary conversion goals:

- Book an appointment
- Call the garage
- Send a WhatsApp message

Secondary goals:

- Learn about services
- View previous work
- Build trust through reviews and FAQs
- Ask questions using the AI Chatbot

# User Flows

## User Flow 1 — Book Appointment

User lands on website

↓

Clicks Book Appointment

↓

Booking Modal or Booking Page

↓

Completes Booking Form

↓

Submit Request

↓

Booking Saved (Pending)

↓

Admin Receives Notification

↓

Admin Reviews Booking

↓

Approved OR Alternative Time Suggested

↓

Customer Receives Confirmation

# Key UX Decisions

- Primary Call to Action: Book Appointment
- Hybrid Booking System:
  - Dedicated Booking Page
  - Booking Modal from any page
- AI Chatbot available on every page
- WhatsApp accessible from every page
- Mobile-first navigation
- Every major page ends with a Book Appointment Call to Action
